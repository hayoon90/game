# 셀 먹기 IO (멀티플레이 서버 버전)

링크만 열면 누구나 같은 판에서 함께 하는 io 게임이에요.
게임 세계(먹이·봇·바이러스·모든 셀)는 서버가 한 곳에서 계산하고, 브라우저는 입력을 보내고 화면을 그려요.

## 폴더 구성

| 파일 | 역할 |
|---|---|
| `server.js` | 게임 서버. 게임 화면 파일도 함께 내보내요 |
| `public/index.html` | 게임 화면(브라우저) |
| `package.json`, `package-lock.json` | 필요한 라이브러리 목록 |
| `render.yaml` | Render에 올릴 때 쓰는 설정(선택) |

## 내 컴퓨터에서 먼저 해 보기

Node.js 18 이상이 설치돼 있어야 해요.

```
npm install
npm start
```

브라우저에서 `http://localhost:3000` 을 열면 돼요. 탭을 두 개 열면 서로 보여요.
같은 와이파이의 다른 기기에서는 `http://내컴퓨터IP:3000` 으로 들어올 수 있어요.

## 인터넷에 올리기 (Render 예시)

서버를 올리면 그 주소가 곧 게임 링크가 돼요. 계정 만들기와 올리기는 본인 계정으로 직접 해야 해요.
아래는 Render를 쓰는 방법이에요. 화면의 버튼 이름은 바뀔 수 있어요.

1. **GitHub 계정**을 만들고 새 저장소(Repository)를 하나 만들어요. 이름은 아무거나 괜찮아요.
2. 저장소 화면에서 **Add file → Upload files** 를 눌러요. 이 폴더 안의 `public` 폴더, `server.js`, `package.json`, `package-lock.json`, `render.yaml` 을 끌어다 놓고 **Commit changes** 를 눌러요. (`node_modules` 폴더는 올리지 않아요.)
3. **render.com** 에 GitHub 계정으로 가입해요.
4. **New → Web Service** 에서 방금 만든 저장소를 고르고, 아래처럼 입력해요.
   - Runtime(언어): `Node`
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance type(요금제): `Free`
5. **Deploy** 를 누르고 기다려요. 끝나면 `https://이름.onrender.com` 같은 주소가 생겨요. 이 주소를 친구에게 보내면 돼요.

주소 뒤에 `/healthz` 를 붙여 열었을 때 `ok` 가 보이면 서버가 살아 있는 거예요.

## 알아 둘 점 (Render 무료 요금제 기준)

- 15분 동안 아무도 접속하지 않으면 서버가 잠들어요. 잠든 뒤 첫 접속은 한참(수십 초) 걸릴 수 있어요. 누군가 게임을 하고 있으면 계속 깨어 있어요.
- 서버가 재시작되거나 새로 올리면 진행 중인 판은 초기화돼요. 최고 기록은 각자 브라우저에 저장돼서 남아요.
- 무료 조건은 바뀔 수 있으니 올리기 전에 Render 사이트의 현재 안내를 확인하세요. Fly.io, Railway 같은 다른 서비스에도 같은 코드를 올릴 수 있어요. `npm start` 로 실행하고 `PORT` 환경변수를 쓰는 Node 서버라서 대부분 그대로 돌아가요.
- 접속자가 한 명도 없으면 게임 세계는 멈춰 있어요.

## 설정 바꾸기 (`server.js` 맨 위)

| 이름 | 기본값 | 뜻 |
|---|---|---|
| `BOTN` | 12 | 봇 수 |
| `VIRN` | 12 | 시작 바이러스 수 |
| `FOODN` | 450 | 먹이 수 (클라이언트 변경 없이 바꿀 수 있어요) |
| `MAXP` | 60 | 동시 접속 상한 |
| `S` | 3000 | 맵 크기 |

규칙 숫자(분열 최소 질량 40, 합쳐지는 시간 12초, 가속 1.8배, 시작 무적 3초 등)도 `server.js` 안에서 찾아 바꿀 수 있어요.

## 조작

- 이동: 마우스 / 손가락 방향
- 분열: 스페이스 / 분열 버튼
- 가속: W 누르고 있기 / 가속 버튼 누르고 있기
- 질량 뱉기: E / 뱉기 버튼
